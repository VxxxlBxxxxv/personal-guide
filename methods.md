# Методы

## Bottleneck: M1 (ресурс)

На ступени 2 достаточно **двух методов** одновременно. Больше — ресурс не тянет; меньше — нет сдвига.

### METHOD.001 — Инвестирование и учёт времени (степень 1→2)

**Can-do:** трекер запущен, ≥5 ч инвестированного на неделе, помидорки 25+5.

Проекты в трекере:
- «Моя работа» = рабочие задачи (тикеты, pull request, ревью, документация, чтение спек).
- «Личные проекты» = pet-projects, эксперименты, learning.
- «Досуг» = третий слой (связь с METHOD.006).

Главное: включать трекер перед работой, даже если потом забросишь — запись о том, что не удержался, важнее пустой недели.

### METHOD.006 — Организация досуга (степень 1)

**Can-do:** режим сна фиксирован, отдых между помидорками на экран не уходит.

Для Knowledge Worker это отдельная задача: ты часто работаешь в том же устройстве, на котором досуг (тот же ноутбук). Физическое разделение пространств обязательно. Это не параллельный проект — это условие, чтобы METHOD.001 вообще работал.

## Правило движения

Степень мастерства по каждому методу — **не более 2 (Умение)** на этой ступени. Прыжок «быстро освою 3 степень в письме» типично ломает ритм: ресурс уходит в один метод и остальные проседают.

## Критерий перехода на ступень 3

- Эпизодическая практика переросла в ежедневную (≥5 слотов/нед в течение 2+ недель подряд).
- W-индекс дошёл до 3 (есть рабочий язык «я — система», человек описывает свой ритм в системных терминах, не эмоциональных).

Пока хотя бы один критерий не выполнен — остаёмся на Практикующем.

## Типы работ, в которые встраиваются методы (Knowledge Worker)

| Метод | Во что встраивается |
|-------|---------------------|
| METHOD.001 | Проект «Моя работа» в трекере = рабочие задачи. Проект «Личные проекты» = pet-projects, эксперименты. |
| METHOD.003 | Чтение RFC, спецификаций, чужого кода, статей в SoTA-области. Двойной экран — читать + заметки. |
| METHOD.004 | Design docs, ADR, PR-описания, технические посты. Исчезающие заметки — комментарии в коде и inbox-папка. |
| METHOD.005 | Ревью кода и дизайнов, парное программирование, архитектурные обсуждения, скрам-события. |
| METHOD.006 | Разделение рабочих и досуговых пространств (тот же ноутбук = зона риска). |
| METHOD.007 | Команда + инструменты + каналы (слэки, RSS, подписки). Пересмотр каналов — первый разворот наружу. |
| METHOD.008 | Выбор между «вглубь стека», «вширь новый домен», «вверх архитектор/tech lead». |
| METHOD.009 | Интеграция с календарём работы, спринты, квартальные цели. «Мои работы» vs «командные задачи». |
