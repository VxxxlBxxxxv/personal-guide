# День: 18 май 2026 (пн)

## Тактика дня

**Одно действие: включи трекер на 25 минут в любой момент дня.**

- **Время:** Утро, обед, вечер — неважно. Главное — до конца дня.
- **Место:** Где ты удобно открываешь свой рабочий инструмент (ноут, планшет, даже телефон — если кодишь/пишешь там).
- **Чем заполнить 25 минут:**
  - Прочитай начало одной статьи / спецификации / README из своих закладок.
  - Напиши один абзац в любой проект (design doc, заметка, комментарий в коде).
  - Потрать 20 минут на размышление о текущем архитектурном вызове, потом 5 минут запиши один вывод.

**Критерий закрытия дня:**

Трекер включён и остановлен. Не важно, что ты делал — важно, что ты начал и закончил.

## Вопрос для рефлексии (конец дня)

Отправь себе одно сообщение или запись в файл `history/2026-05-18-reflection.txt`:

**"Что помешало / что помогло закрыть слот сегодня — внешнее (обстоятельства, люди, уведомления) или внутреннее (состояние, внимание, уверенность)?"**

Примеры ответа:
- "Помогло: выключил Slack перед слотом. Мешало: позвонил коллега в середине."
- "Помогло: сделал слот сразу после кофе. Мешало: не было, слот прошёл легко."

Эта рефлексия копится в истории и используется для корректировки завтра.

## Что НЕ делай сегодня

- Не ставь высокую планку ("буду читать серьёзный учебник").
- Не жди идеального состояния ("начну, когда спринт закончится").
- Не оценивай качество ("мало получилось, не считается").
- Не откладывай на завтра — сегодня же.

## После закрытия слота

Открой файл `history/2026-05-18-reflection.txt` и добавь одну строку:
```
2026-05-18: [время]  [что делал] | [что помогло / мешало]
```

Примеры:
```
2026-05-18: 25 мин  Читал RFC по кэшированию | Помогло: выключил звуки. Мешало: первые 5 мин был рассеян.
2026-05-18: 25 мин  Писал дизайн для компонента | Помогло: чай. Мешало: открывал Slack два раза.
```
